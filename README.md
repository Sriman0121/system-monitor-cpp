# System Monitor (Linux C++)

A terminal-based monitoring dashboard using **C++17 and /proc**
showing:
- Total & per-core CPU usage
- Memory usage
- Top processes by CPU & RAM
- Live terminal dashboard UI

## Build & Run
make part5
./bin/part5-dashboard 5 1 5

## Tech
C++17, procfs, Makefile, Linux
